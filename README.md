# 지스타 2026 출품 게임 가이드 (비공식)

지스타 2026(부산 벡스코, 2026.11.19~22) 출품 게임을 장르별로 정리한 비공식 관람 가이드입니다.

- 사이트: https://weritas247.github.io/gstar2026-guide/
- 기능: 장르 탭, 시연 가능 게임만 보기, 검색, 게임별 회사·게임 페이지·출처 링크
- 데이터 수정: `data.js` 한 파일만 고치면 사이트에 반영됩니다.
- 데이터 기준일: 2026-10-29 (보도·공식 발표 기준, 미확인 정보는 사이트에 별도 표기)

공식 정보는 https://gstar.or.kr 에서 확인하세요.
